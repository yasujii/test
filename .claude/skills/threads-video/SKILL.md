# Threads/リール ショート動画スキル

縦型ショート動画（Threads / Instagramリール / TikTok）を作るためのスキル。

**このスキルの前提**: 動画は「作り込む」ものではなく「量産する」もの。クオリティを上げすぎず、**80点を量産**する。1本に何時間もかけた動画より、80点を10本出したほうが伸びる。

---

## 入力ヒアリング

以下を受け取る。不足があれば聞き返す。ただし全部埋まらなくても、既定値で進めてよい。

1. **ジャンル・テーマ**（例：腸活、更年期、ADHD、副業）
2. **尺**（既定：**25秒**／選択肢：15秒・25秒・40秒）
3. **元ネタ**（既存のThreads投稿を転用するのか、新規か）
4. **話者**（顔出し／音声のみ／文字のみのスライド動画）
5. **出力先**（Threads／リール／TikTok。既定は3つとも同じ素材を使い回す）

---

## STEP1：リサーチ

**TikTokから企画を拾う。** Instagramやスレッズより、TikTokのほうが伸びている型が早く可視化される。

手順は4つ。

1. 載せたいジャンルのキーワードでTikTok検索
2. 検索結果の**ユーザー欄**から投稿を見ていく
3. **5アカウントから2本ずつ、計10本**抽出する
4. 抽出基準は**再生数がフォロワー数の10倍以上**であること

再生数がフォロワーの10倍を超えているものは、フォロワー以外に届いた動画。つまり「型が勝っている」証拠になる。フォロワー数と再生数が同じくらいの動画は、ファンが見ているだけなので参考にならない。

抽出したら、各動画について次を記録する。

- 最初の2秒で何が映っていたか（文字／人物／手元／ビフォーアフター）
- 冒頭の一言
- 尺
- 字幕の出し方（全文／キーワードのみ）
- 最後のCTA

---

## STEP2：台本作成

### 動画のフックは「文字」と「絵」の両方で作る

テキスト投稿のフックは1行目がすべてだが、**動画は0〜2秒の画と音と文字の3点セット**で決まる。ここを外すと、どれだけ中身が良くても最後まで見られない。

0〜2秒で必ず入れるもの。

- **画面いっぱいの文字**（スマホで指を止めさせるのは文字。絵じゃない）
- **断言か問いかけ**（「〜かもしれません」は絶対に使わない）
- **動きのある絵**（静止画スタートは離脱率が跳ね上がる。ズームかカットで動かす）

### 秒単位のタイムライン構成（25秒の場合）

| 秒数 | 役割 | 中身 |
|---|---|---|
| **0:00–0:02** | フック | 大きい文字＋断言。ここだけで7割決まる |
| 0:02–0:05 | 共感・問題提起 | 「〜してない？」で自分ごと化させる |
| 0:05–0:20 | 本題 | 具体を3つまで。4つ以上は覚えられない |
| 0:20–0:23 | まとめ | 結論を1文で言い切る |
| 0:23–0:25 | CTA | 保存・コメント・フォローのどれか1つだけ |

15秒なら本題を2つに、40秒なら本題を3つのまま各項目を厚くする。**項目数を増やすのではなく、1項目を深くする。**

### 動画用フック20型

テキスト用のフック型はそのまま使えるが、**動画では1文を短く切る**。読み上げ速度に合わせる必要があるため、1カットあたり15文字前後が上限。

| 型 | 動画での冒頭例（0〜2秒に出す文字） |
|---|---|
| 断言系 | 「納豆、朝に食べてる人 損してます」 |
| 今すぐやめて系 | 「その腸活、逆効果です」 |
| 9割が知らない系 | 「9割が知らない 食物繊維の落とし穴」 |
| 警告系 | 「8月後半、体調崩す人へ」 |
| 問いかけ系 | 「朝のトイレ、何分かかってる？」 |
| 数字インパクト系 | 「月15,000円、全部ムダでした」 |
| 第三者ストーリー系 | 「母が便秘薬をやめた日の話」 |
| 体験談系 | 「3年前の自分に言いたい」 |

**フック型は毎回変える。** 同じ型を連投すると既存フォロワーのスクロール速度が上がり、初速が落ちる。

### 台本の出力形式

必ずこの形式で出す。そのままCapCutや自動編集に流せるようにするため。

```
[0:00-0:02] テロップ: その腸活、逆効果です
            画:     アップの手元／冷たい飲み物にズーム
            音声:   その腸活、逆効果かもしれません。

[0:02-0:05] テロップ: 真面目な人ほどハマる
            画:     カット切り替え／表情
            音声:   真面目にやってる人ほど、ハマります。
```

## STEP3：動画化

### この環境で使えるもの

| やりたいこと | 使うもの |
|---|---|
| 画像1枚から動画（ズーム・フェード・テロップ） | リポジトリの `video_editor.py` |
| 動画の切り出し・つなぎ | Adobe MCP `video_create_quick_cut` |
| 縦型へのリサイズ（9:16） | Adobe MCP `video_resize` |
| 静止デザインをアニメーション化 | Adobe MCP `animate_design` |
| ナレーション音声のノイズ除去 | Adobe MCP `media_enhance_speech` |
| フレーム書き出し・最終レンダリング | Adobe MCP `video_render` / `video_render_frame` |
| 素の変換・結合 | `/opt/pw-browsers/ffmpeg-1011/ffmpeg-linux` |

Adobe MCPを呼ぶ前に、必ず `adobe_mandatory_init` を先に実行する。

`video_editor.py` を使う場合は Pillow が必要。入っていなければ `pip install Pillow` を先に走らせる。

### 動画の基本仕様

- **解像度**: 1080×1920（9:16の縦型）
- **尺**: 15〜40秒。既定は25秒
- **字幕**: **必ず入れる**。音声オフで見る人が大半なので、字幕なしは成立しない
- **文字サイズ**: 画面幅の8割を使う大きさ。小さい文字は読まれない
- **セーフエリア**: 上下に150pxずつ余白。UIに隠れる

## STEP4：投稿とバズ判定

投稿したら**1時間後に必ずインプレッションを見る**。

| 1時間後 | 判断 |
|---|---|
| **1,000インプ超え** | バズ判定ON。リプ欄に動線（オプチャ／note／アフィリ）を貼る |
| 1,000インプ未満 | その動画は基本そのまま伸びない。粘らず次に切り替える |

**初期アカウントは、最初からリンクを貼らない。** 垢バン直行になる。必ずバズ判定が出てから貼る。

投稿は基本伸びない前提で回す。**3日に1回バズれば十分売れる。**

## 絶対遵守ルール

台本のテロップ・ナレーション・キャプションすべてに適用する。

1. **emダッシュ（——）禁止**
2. **ダブルクォート禁止**（日本語の引用は「」）
3. **ハッシュタグ禁止**
4. **「死」関連ワード完全禁止**（死ぬ／自殺／亡くなる等。比喩・誇張も含めて禁止）
5. **AI語彙の排除**（効率化／最適化／変革／強化／最大限／飛躍的／革命的／画期的／シームレス／活用）
6. **3要素並列を避ける**（「A、B、そしてC」型の整いすぎた構造）
7. **否定パラレルを避ける**（「〜だけでなく〜も」型）
8. **埋め草フレーズを削除**（「重要なのは」「結論から言うと」）
9. **医療・健康ジャンルでは断定を避ける**（「治る」「痩せる」は使わない。医師の引用か個人の感想の範囲に収める）
10. **いいね誘導禁止**（「いいね◯件で続き」等）

## 既存のThreads投稿を動画に転用する場合

これが一番速い。ゼロから考えなくていい。

1. **すでに伸びた投稿を選ぶ**（1時間1,000インプを超えたもの）
2. **3スライドツリーは25秒動画にちょうど合う**。フック=0〜2秒、本題=5〜20秒、まとめCTA=20〜25秒にそのまま対応する
3. テキストのままだと1文が長いので、**1カット15文字前後に切り直す**
4. 数字と固有名詞は必ず残す。ここが動画の説得力になる

逆にやってはいけないのは、伸びなかった投稿を動画にすること。テキストで伸びなかった企画は、動画にしても伸びない。**テキストで勝ってから動画にする。**

## 出力前チェックリスト

- [ ] 0〜2秒に画面いっぱいの文字が入っている
- [ ] 冒頭が断言か問いかけになっている（「かもしれません」で始まっていない）
- [ ] 静止画スタートになっていない（動きがある）
- [ ] 本題の項目が3つ以内
- [ ] 字幕が全編に入っている
- [ ] CTAが1つだけ（複数入れると全部やられない）
- [ ] 1カットあたりの文字数が15文字前後に収まっている
- [ ] 尺が指定どおり（既定25秒）
- [ ] 9:16の縦型になっている
- [ ] 絶対遵守ルール10項目に違反していない
- [ ] 台本が秒単位のタイムライン形式で出力されている
