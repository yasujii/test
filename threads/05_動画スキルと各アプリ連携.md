# 動画スキルと、各アプリでの連携手順

## 作ったもの

`.claude/skills/threads-video/` に**動画スキル**を作りました。

| ファイル | 中身 |
|---|---|
| `SKILL.md` | リサーチ→台本→動画化→バズ判定の全手順。動画用フック20型、秒単位の構成テンプレ、絶対遵守ルール10項目 |
| `references/腸活サンプル台本.md` | 既存投稿から変換した25秒台本3本（完成品） |
| `dist/threads-video-skill.zip` | claude.aiにアップロードする用のパッケージ |

次回から「腸活の動画作って」「この投稿を動画にして」と言うだけで、秒単位のタイムライン台本が出ます。

---

## 各アプリでの使い方

### Claude Code（CLI / claude.ai/code / デスクトップ版）

**設定はもう終わっています。** スキルはリポジトリの `.claude/skills/` に入れてコミット済みなので、このリポジトリを開いたセッションでは自動で読み込まれます。追加作業はありません。

### claude.ai モバイルアプリ / デスクトップアプリ / Co-work

**ここだけ、1回だけ手作業が必要です。**

`dist/threads-video-skill.zip` を、claude.aiの **設定 → Capabilities（スキル）** からアップロードしてください。アカウントに紐づくので、**1回上げればモバイル・デスクトップ・Co-workの全部で使えます。**

Co-workはデスクトップアプリの機能なので、デスクトップに入れば自動的にCo-workでも使えます。

**私がこのアップロードを代行することはできません。** claude.aiのアカウント設定を操作するツールがこのセッションにないためです。ZIPは作ってあるので、ダウンロードして上げるだけです。メニューの名前はUIの更新で変わることがあるので、「スキル」か「Capabilities」を探してください。

## 動画作成に使えるツール（この環境で確認済み）

| やりたいこと | 使うもの | 状態 |
|---|---|---|
| 画像1枚から動画（ズーム・フェード・テロップ） | `video_editor.py`（リポジトリ内） | Pillowの追加インストールが必要 |
| 動画の切り出し・つなぎ | Adobe MCP `video_create_quick_cut` | 利用可 |
| 縦型9:16へのリサイズ | Adobe MCP `video_resize` | 利用可 |
| 静止デザインのアニメーション化 | Adobe MCP `animate_design` | 利用可 |
| ナレーションのノイズ除去 | Adobe MCP `media_enhance_speech` | 利用可 |
| 最終レンダリング | Adobe MCP `video_render` | 利用可 |
| 変換・結合 | `/opt/pw-browsers/ffmpeg-1011/ffmpeg-linux` | 利用可 |

Adobe系を使うときは、先に `adobe_mandatory_init` を呼ぶ必要があります。スキル内に書いてあります。

## Xの投稿が読めなかった件

`https://x.com/makeai_ceo/status/2081253131996872764` は**取得できませんでした。**

3通り試して全部ダメでした。

1. WebFetch → 403
2. Web検索 → 該当投稿の本文はヒットせず（アカウントが `@MakeAI_CEO`＝株式会社MakeAI CEO まなさん、であることは確認）
3. **Chromiumで実ブラウザとして開く** → `ERR_TUNNEL_CONNECTION_FAILED`

3番目でプロキシのログを見たところ、原因がはっきりしました。

```
"kind": "connect_rejected",  "host": "x.com:443"
```

**x.com そのものが、この環境のネットワークポリシーで遮断されています。** ログインの問題ではなく、接続自体が許可されていません。ブラウザを使っても抜けられません。
