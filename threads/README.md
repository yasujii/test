## 最初に：予約投稿の「登録」だけはできませんでした

依頼のうち、**Threadsアプリへの予約投稿の登録そのものは実行できていません。**

理由は2つです。

1. このセッションに**Threads / Metaの連携（コネクタ）がありません。** 使えるのは Google Drive・Gmail・Google Calendar・Indeed のみで、Threadsに投稿を書き込む手段が存在しません。
2. Threadsは**ログインなしのアクセスを403で拒否**します。プロフィールも投稿ページも読めませんでした（`threads.com` / `threads.net` 両方で確認済み）。

**なので「中身は全部作った、登録だけ手作業」の状態で納品します。**
`03_投稿本文_7日分.md` はコードブロック1つが1投稿になっているので、コピー → Threadsの予約投稿画面に貼り付け → 日時を指定、の繰り返しで済みます。**21枠で15〜20分程度**の作業です。

ここは正直にお伝えしておきます。ごまかして「予約しておきました」とは書けません。

### 第1週で見つかって直した欠陥2つ

## 何をやったか

### 1. スレッズを徹底的に分析した

Google Driveの `threads_腸活_バズ投稿.xlsx` を軸に、**腸活ジャンルのバズ投稿22件／12アカウント／合計21,004いいね**を全文分析しました。

分かったこと（詳細は `01_` に）:

- **「消化器内科の先生に言われた」型が22投稿中9投稿を占める**。このジャンルの一軍フック
- 伸びてる投稿は全部 **食品名 × 分量 × 期間** の3点セットが入ってる
- **フォロワー4,375人で4,469いいねを出してるアカウントがある**。フォロワー数は言い訳にならない
- 上位はほぼ全部 **腸活 × 何か**（血液型 / 薬膳 / 更年期 / 閉経後）のニッチ掛け算

### 2. 400インプレで止まってる原因を診断した

結論、**1行目です。**

直近の投稿として確認できたキムチのネタは着眼点自体は正解でしたが、1行目に「情報」を置いています。伸びてる投稿は1行目に**感情か、事件か、名指し**を置いています。

```
✕  スーパーのキムチは発酵していないものが多い
○  正直、裏切られた気分だった。毎週買ってた198円のキムチが、実は発酵してなかった。
```

あわせて、ターゲットが名指しされていない点と、季節性を使えていない点も原因として挙げています。

### 3. 7〜8月の季節性で全枠を組み直した

4月のリサーチは「更年期」「花粉症」が中心でした。**いまは夏腸活が年間最大の追い風です。**

冷たい飲み物 / 冷房 / 素麺 / 脱水 / お盆の帰省。今まさに悩んでる人の絶対数が多いので、同じ型でもリーチが伸びます。**21枠すべて夏腸活で統一しました。**

### 4. 3-slide-tree-post スキルで書いた

指定どおり `3-slide-tree-post` スキルの構成（フック → 本題 → まとめ＋CTA）と出力ルール（スライド番号なし / 1スライド1行 / 区切り線なし / いいね誘導なし）に従っています。

**朝＝3スライドツリー、昼＝単発投稿、夜＝3スライドツリー**の指定どおりです。

## 投稿前に必ずやってほしいこと

**体験談の数字を、さくらさんの実際の体験に書き換えてください。**

「3年で50万使った」「母が10年便秘薬を飲んでいた」などは、**バズ型を再現するために置いた枠**です。このジャンルはリアルな体験談かどうかで伸びが変わりますし、嘘の体験談は長期的にアカウントを壊します。設定と数字はご自身のものに合わせてください。

医療表現は「治る」「痩せる」を避け、医師の引用か個人の感想の範囲に収めてあります。ここは崩さないでください。

## 投稿後にやること

1. **投稿後30分はコメントに全返信。** Threadsは初速30分の反応率で配信量を決めます。ここが一番効きます
2. **インプレッション・いいね・コメント数を毎日記録。** どの型が跳ねたかを来週に反映します
3. **跳ねた翌日は反響報告投稿を差し込む。** 「昨日の投稿、反響すごくて…」だけで1本成立します（実例で161いいね）

### 今週の現実的な目標

| 指標 | 現状 | 今週 |
|---|---|---|
| 平均インプレッション | 約400 | 1,500〜3,000 |
| 週内の最高値 | ー | 1本だけ10,000超を狙う |

いきなり全投稿を1万にするのは無理です。**21投稿撃って1〜2本跳ねさせ、その型に来週寄せる**のが最短ルートです。

## 補足：直近1〜2ヶ月のデータについて

「直近1〜2ヶ月のバズ投稿を手探りしてほしい」という点について、**新規スクレイピングはできていません**（上記のとおりThreadsが403）。数値ベースの一次データは4月時点のものです。

ただし4月データは22投稿の全文・型・いいね数が揃った密度の高いもので、**どの型が伸びるかという構造は数ヶ月で陳腐化しません。** 構造は4月データ、ネタは7〜8月の季節性で更新する、という設計にしています。

直近データが必須であれば、**Claude in Chrome が使える環境で `threads-topic-research` スキルを回す**のが最短です。このリモート環境ではブラウザ連携が使えませんでした。
