## 1. 勝ちパターンの構造分析（22投稿・21,004いいねから）

### 1-1. 型別の成績

| 順位 | 投稿の型 | 該当数 | 代表いいね |
|---|---|---|---|
| 1 | **体験談＋クリフハンガー型** | 6投稿 | 2,094 / 852 / 646 |
| 2 | **箇条書き網羅型** | 3投稿 | 827 / 393 / 229 |
| 3 | **知識・豆知識型** | 3投稿 | 2,575 / 440 / 101 |
| 4 | 権威性＋断言型 | 2投稿 | 2,407 / 1,052 |
| 5 | 常識破壊型 | 2投稿 | 362 / 100 |

平均955いいね／48コメント／11リポスト。

### 1-2. 圧倒的支配パターン：「消化器内科医に言われた」

**22投稿中9投稿**が医師の引用から入っています。これがこのジャンルの一軍フックです。

構造はほぼ共通です。

```
[身近な人]が[症状]で悩んでた
 → 病院/市販薬ではダメだった
 → 消化器内科の先生に「[意外な一言]」と言われた
 → 半信半疑で[期間]続けた
 → [具体的な変化]
 → で、先生に報告したら、なんと、、、  ← ここで切る
```

最後の「切り」が2枚目のクリック率を作っています。**@hakkou_san（2,094いいね）、@ketto_kun2（852いいね）、@diet_health_yama（646いいね）が全員この型です。**

### 1-3. 全バズ投稿に共通する3点セット

> **具体的な食品名 × 分量 × 期間**

- 「黒ごま 毎朝大さじ1 × 3ヶ月」→ 4,469いいね
- 「きな粉 大さじ2 ヨーグルトに × 1ヶ月」→ 852いいね
- 「大根おろし 夜 × 1週間」→ 369いいね
- 「もち麦 1日大さじ2」→ 101いいね

**「腸にいいものを食べましょう」では絶対に伸びません。** スーパーで買える固有名詞・大さじ何杯・何週間、この3つが揃って初めて「自分にもできる」に変わります。

### 1-4. 権威性の作り方（医師じゃなくても作れる）

| パターン | 実例 |
|---|---|
| 医師の引用 | 「消化器内科の先生に言われた」（最多9件） |
| 家族経由の引用 | 「母が言われたんやけど」← **自分が医師である必要がない** |
| 専門用語の投下 | SIBO / NAFLD / 腹腔神経叢 / β-グルカン / ゴイトロゲン |
| 自分の現場経験 | 「総合病院で10年働いてるんですが」 |

**@sakura_cyoukatsu が今すぐ使えるのは「家族経由の引用」と「専門用語の投下」です。** 医療資格は要りません。専門用語を1つ入れるだけで滞在時間が伸びます。

### 1-5. ニッチの掛け算が飛び抜けている

いいね数トップ層は全員「腸活 × 何か」です。

- 血液型 × 腸活 × 甲状腺（@ketsuryu.chan / 4.4万フォロワー）
- 薬膳 × 腸活（@bihatsu_usagi / 4,375フォロワーで **4,469いいね**）
- 閉経後NAFLD × 腸活（@rese.and.natur）
- 腹腔神経叢 × みぞおち押し（@diet_health_yama）

**注目すべきは @bihatsu_usagi です。フォロワー4,375人で4,469いいね。フォロワー数を超えるいいねが出ています。** つまり**フォロワーが少なくても、切り口さえ立てば1万インプレは届く**という証拠です。ここが今回いちばん重要な発見です。

## 2. 400インプレで止まっている原因の診断

Threadsのアルゴリズムは「最初の30分の反応率」でその後の配信量を決めます。400で止まるのは、リーチの問題ではなく**1行目の問題**である確率が高いです。

### 診断①：1行目が「情報」になっている（最重要）

直近の投稿として確認できたキムチのネタは、**着眼点自体は完全に正解**です（バズ型でいう「常識破壊型」）。ただしこのジャンルで伸びている投稿は、1行目に情報を置いていません。**感情か、事件か、名指しを置いています。**

```
✕  スーパーのキムチは発酵していないものが多い
○  正直、裏切られた気分だった。毎週買ってた198円のキムチが、
   実は発酵してなかった。
```

同じネタでも、後者は「何があったの？」で指が止まります。

### 診断②：ターゲットが名指しされていない

伸びている投稿は0.3秒で「自分のことだ」と分かります。

- 「40代で毎食ササミ100g食べてた人へ」
- 「O型さん限定」
- 「発酵食品を毎日食べてもガス溜まりするヤツ」

**「腸活したい人」では広すぎて誰も止まりません。** 今回の7日分は全枠でターゲットを名指ししています。

### 診断③：ツリーを使えていない可能性

データ上、**上位投稿の多くが1/3〜1/4のツリー型**です。ツリーは1投稿あたりの滞在時間を伸ばし、アルゴリズム評価を直接押し上げます。今回「朝と夜は3スライドツリー」という構成にしたのは、この一点で正しい判断です。

### 診断④：季節性を使えていない

4月のバズは「更年期」「花粉症」が中心でした。**いま7月末〜8月は、腸活にとって年間最大の追い風シーズンです。**

- 冷たい飲み物・アイスで腸が冷える
- 冷房で自律神経と腸が同時にやられる
- 素麺・冷やし中華で食物繊維とたんぱく質が枯渇する
- 汗で脱水 → 夏の便秘
- お盆の帰省・旅行で生活リズムが崩れる

**この季節ネタは「今まさに悩んでいる人」の絶対数が多いので、同じ型でもリーチが伸びます。** 今回の7日分は全枠を夏腸活で設計しました。

## 3. 1万インプレに乗せるための実行方針（今週やること）

| # | 方針 | 具体 |
|---|---|---|
| 1 | 1行目を感情・事件・名指しに変える | 全21枠でフック型を指定済み |
| 2 | 医師/家族引用を週2回入れる | 7/30夜・8/1夜に配置 |
| 3 | 食品名×分量×期間を必ず入れる | 全枠で徹底 |
| 4 | 専門用語を週3〜4回投下する | SIBO・短鎖脂肪酸・水溶性食物繊維・蠕動運動・セロトニン |
| 5 | 夏の季節ネタで固める | 7日分すべて夏腸活 |
| 6 | 朝夜はツリーで滞在時間を稼ぐ | 3スライド×14本 |
| 7 | 最終日にリスト導線を作る | 8/5夜でコメント誘導→PDF配布 |
| 8 | 投稿後30分はコメント全返信 | 初速の反応率がその後の配信量を決めるため |

### 数値目標（今週の現実的なライン）

| 指標 | 現状 | 今週の目標 |
|---|---|---|
| 平均インプレッション | 約400 | 1,500〜3,000 |
| 週内の最高インプレッション | ー | 1本だけ10,000超を狙う |
| コメント数／投稿 | ー | 3件以上 |

**いきなり全投稿を1万にするのは無理です。** 現実的には「21投稿撃って、そのうち1〜2本が跳ねる」形になります。跳ねた型を来週その方向に寄せる、という運用が最短です。伸びた投稿の型は必ず記録してください。

## 4. 来週以降に効いてくる仕込み

1. **キャラの固定** — バズ12アカウントは全員「この人といえば○○」が明確です。「さくら＝夏の腸活の人」「さくら＝スーパーで買えるものだけで腸活する人」など、1つに寄せると復リピートバズが出ます。
2. **反響報告型の活用** — @ketsuryu.chan は「昨日の投稿の反響」を翌日投稿にして、それ自体を161いいねにしています。バズった翌日は必ず反響報告を挟んでください。
3. **PDF配布によるリスト化** — このジャンルの収益導線はほぼ全て「コメント誘導→PDF/LINE配布」です。直接的なアフィリ訴求はバズ投稿にほぼ存在しません。8/5夜の投稿をその起点にしています。
